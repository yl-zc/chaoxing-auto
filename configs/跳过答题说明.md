# 跳过答题（skip_quiz）开关

- 开关位置：`engine/config.json` → `answer.skip_quiz`（同步副本：`configs/engine-config.json`）。
- 切换方式：双击包根目录的 **切换跳过答题.cmd**（推荐），或手动编辑上述 JSON。
- 默认值：`false`（正常流程：课程视频 + 章节测验 + 提交）。
- 设为 `true`：只做课程视频；不做章节测验、不回填、不提交任何答案；
  该节 run.json 记 `status=skipped_quiz`/`skipped_quiz=true`，队列守护记 `section_skipped_quiz` 并继续下一节。
- 生效时机：新的计划（或重启启动器后）生效；队列守护运行中会读取最新配置。
- 其它相关：`answer.enabled` 为答题模块总开关（默认 true），`pipeline.min_conf` 为提交闸门最小置信度（默认 0.8）。
