## 2. 构建步骤（M0）

| 步 | 命令 / 动作 | 期望 |
|---|---|---|
| 1 | `python -m venv work\.venv`（python = 本机 3.13.9） | venv 生成 `Scripts\python.exe` |
| 2 | `work\.venv\Scripts\python.exe -m pip install playwright` | 安装成功（**不**下载浏览器内核） |
| 3 | 用系统已装 Chrome 作为 playwright 通道（`channel="chrome"`） | 不触发浏览器内核下载（Q11） |
| 4 | 启动独立 Chrome：`--remote-debugging-port=9222 --user-data-dir=work\chrome-profile` | CDP 9222 监听；**仅独立实例** |
| 5 | 用户在场扫码登录（Q19） | 登录态落在独立 profile，不写凭据文件 |

- 依赖最小集：`playwright`（+ 原包另需 `websocket-client`；zstandard / Pillow 按实际 import 补，**未验证**）。
- 禁止：pip 装到系统 Python、下载模型/浏览器内核、关用户 Chrome 窗口。

## 3. 启动 / 停止

| 场景 | 命令（目标形态） |
|---|---|
| 自检 | `python run.py --doctor`（缺依赖 exit 2 并列缺项） |
| 路径自检 | `python run.py --plan --json`（打印实际解析后的 profile/evidence/verify/STOP 路径） |
| 单节 | `python run.py --play --section 2.1` |
| 批量（仅确认后） | `python run.py --batch`（Q12：先单节验证，禁止一次性全量） |
| 停机 | 在**解析后的** STOP 路径建 STOP 文件（v2 起由 `stop_requested(cfg)` 纯函数判定） |
| 强停 | 结束对应 python 进程 + 关独立 Chrome 实例 |

### 退出码约定（v2）

| 码 | 含义 |
|---|---|
| 0 | 全部完成且判分通过 |
| 1 | PENDING（判分未出结论，需重跑） |
| 2 | 冲突 / 停止 / 有失败 |
| 3 | 程序异常（含 GBK 编码崩溃，**不再与 PENDING 混淆**） |
| 4 | 判分未完成（verify 缺失或 rc≠0 → completed_unverified） |

## 4. 逐节运行协议（Q5 + Q21 + Q12）

| 步 | 动作 | 人工参与 |
|---|---|---|
| 1 | 确认下一节节号（用户指定，默认 2.1→2.2→2.3） | 用户 |
| 2 | 起独立 Chrome → 确认已登录 → 跑该节 | 用户仅扫码/确认登录 |
| 3 | 节内全自动：2x 上限 + 静音 + 允许后台/最小化 | 无 |
| 4 | 节末留证据：`2→1` 截图、`jobUnfinishCount`、`play_samples.jsonl`、判分报告 | 无 |
| 5 | 把证据给用户 → **用户确认后**才跑下一节 | 用户 1 次 |
| 6 | 任一步异常：停机、留证、不自动跨节 | 无（异常即停） |

## 5. 每节证据要求（Q8/Q17）

| # | 证据 | 判据 |
|---|---|---|
| 1 | 播放前截图 | `jobUnfinishCount=2`（或当前值） |
| 2 | 播放中截图 | 播放器在播、2x/静音生效 |
| 3 | 结束后截图 | `jobUnfinishCount=1`，课程进度 +1 |
| 4 | `play_samples.jsonl` | 采样连续、时长接近视频时长 |
| 5 | 判分报告 | 三态结论之一，**不接受 skipped 当 completed** |

## 6. 扫码登录说明

1. 只用独立 Chrome 实例（`work\chrome-profile`），不接管用户窗口；
2. 由用户本人在该实例里扫码；
3. 登录态只存在于该 profile 目录，不写明文凭据、不入交付包；
4. 掉登录 → 停止该节、请用户重新扫码，不猜密码、不自动重试登录。

## 7. 常见故障

| 现象 | 原因 | 处置 |
|---|---|---|
| 控制台乱码 / UnicodeEncodeError | pwsh 默认代码页 936（GBK），脚本打印 `⇒`、`↔` | v2 已修：异常统一 exit 3；临时可设 `PYTHONIOENCODING=utf-8` |
| 报错 exit 1 被当成 PENDING | v1 的编码崩溃与 PENDING 同码 | v2 起 exit 3 区分（修复前必须看输出有无 Traceback） |
| CDP 连不上 | Chrome 未起 / 端口被占 / 实例被杀 | 检查 9222 监听、重起独立 Chrome；**不要**去连用户 Chrome |
| 路径错 `E:\test\…` | v1 的 P0-1（config.yaml 写死 7 处） | v2 已相对化；跑 `--plan --json` 核对解析值 |
| 没判分却 completed | v1 的 P0-2（verify 缺失静默跳过） | v2 已修：skipped/rc≠0 → completed_unverified + exit 4 |
| STOP 文件不生效 | v1 的 P0-3（写死 STOP 路径） | v2 已修：按 cfg 键解析；建 STOP 前先 `--plan --json` 看路径 |
| 时长估算偏大/偏小 | 原文档 3h07m 是单节外推，实测均值 658s/节 | 按 24 节 ≈ 4.4h、28 节口径 ≈ 5.1h 规划 |

> 本文所有"v2 已修"项以 M1 完成并通过独立复核为准；复核未过一律按未修复对待。
