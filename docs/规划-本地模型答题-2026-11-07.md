### 3.3 文本归一化规则（作用于视觉识别转写文本；写入 quiz.py 规范）

1. Unicode NFKC 归一（全角→半角、兼容字符）；去首尾空白；连续空白折叠；保留题干/选项分行语义。
2. 选项**显示字母**归一：A/B/C/D、A.、A、、（A）→ 单字母（**仅展示标识，不映射提交码**）；判断题 正确/错误、对/错、T/F、√/× → true/false。回填时按「显示字母 → 选项元素」点击，提交码由页面计算（§3.0②）。
3. 填空：下划线/括号/空 span 统一为占位符 `{{BLANK_n}}`，按 DOM 顺序编号，与 blanks 数对齐。
4. 富文本：公式（MathML/图片）、代码、上下标保留原文，不强行转写；识别不确定则整题 unknown。
5. 去重与配对：题干+选项做哈希（stem_hash），记录 DOM 顺序与可见顺序，供乱序核对。

### 4.4 提示词与推理策略

- **逐题独立请求**（题与题不共享上下文，避免串题）；整卷上限 20 题。
- 固定模板按题型分派：单选/多选/判断 → 输出 JSON（value/confidence/rationale）；填空按 blanks 顺序。
- **视觉识别模板（主路径）**：输入 = 每题题干区截图（题干+选项渲染截图），要求输出 JSON（题干转写、**选项显示字母↔文本**、题型、答案 value/confidence/rationale）；**不要求输出提交码**；低置信/复杂公式转 unknown。
- **A→C 两段式（1.2 实测定稿，替代原 B 策略）**：
  1. **A 段（视觉抽取/整题作答）**：VLM 读每题截图，**整题一次**输出答案（含多选组合），保留 rationale/confidence；
  2. **C 段（文本推理交叉验证）**：把 A 的题干转写/选项/答案交给**文本推理**做一致性校验（每选项为何选/不选、组合是否自洽），**3–8 s/题**；与 A 不一致时以 C 给出修正或标 unknown/转人工，一致则放行；
  3. **不再使用 B（多选逐项判断）**：1.2 实测 B 出现**多选全选倾向**（模板化理由）与**单选自检幻觉**（Q2 自检后改错），耗时 296 s 且更差；B 的「漏选告警」仅保留为 A/C 的**后处理提示**（不单独跑模型）。
- 温度 **0**（确定性优先）；固定 seed（运行时支持时）；max_tokens 限制（选择题 ≤64、填空 ≤160）；**强制短输出、关闭 thinking**（方式【待实测】；带 thinking 约 29 s/题，20 题≈10 min，不可接受）。
- **拒答规则**（prompt + 后处理双重校验）：题干/选项不完整、图片题、异常选项数、置信度自评 <0.6、答案 key 不在选项内 → 一律 unknown。
- **覆盖校验（recon 实测缺陷）**：比对请求 index 集合与返回 index 集合，缺题 → unknown 并标记 `coverage_missing`；缺题卷不得进入提交候选。
- 输出后处理：JSON 解析失败 → 重试 1 次 → 仍失败 unknown；value 越界/重复/类型不符 → unknown；confidence 裁剪到 [0,1]。
- 可选 self-consistency：同题采样 2 次取一致（实测短答 0.5–1.1 s/题，×2 仍 <3 s；**默认关**，需要更高把握时逐题开启）。

3. **禁止**为绕开误报而删除或放宽扫描；误报经白名单解决。

**M6 单测（2 条）**：① quiz mock 页扫描 **0 误报**（题型词不触发）；② 视频页/验证码用例**仍能停**（原语义不退化）。

### 6.1 置信度分级

### 6.2 逐题记录（answers.jsonl 必填字段）

### 6.3 人工核对流程

1. 每题显示：题干 + 选项 + 模型答案 + **依据** + 置信度 + 模型原文（截断）；**并核对视觉转写与截图一致**（题干/选项）。
2. 人工判定 对/错/存疑，写入 `review.jsonl`。
3. 首节 **100% 核对**；后续默认**抽检每节 ≥5 题且 ≥30%**（取大者）。
4. 抽检错误率 >10% → 该节升级 100% 核对并暂停下一节；连续两节不达标 → 停线，回 M6 调提示词/换模型/降级。

## 7. 风险与安全

### 7.1 四条红线

1. **不伪造进度**：不改接口报文、不伪造播放/作答记录、不用脚本改点数；进度只由平台真实行为产生。
2. **提交可控**：dry-run **零提交**；提交必须显式开关 + 授权 + 单节确认，绝不默认提交；本轮已**受控测试 1 次（1.1，100/100）**，生产放量仍 G6 未授权。
   - **提交不可逆（已实测）**：1.1 第 1 次作答已用、不可回退；失败/结果未知不重试。
3. **不绕过风控**：不绕验证码、人脸、切屏检测、次数限制；命中即停、留证、上报。
4. **不外泄数据**：题目/答案/截图/账号态不外发；本地推理=不外发；云端 API 属外发，本轮不做。

### 7.2 限速与节奏（不触发风控、不抢资源）

| 截图 | 关键节点 ≤5 张/节 |
| 节间 | 逐节确认（沿用 Q21） |
| 提交（生产） | 单轮 ≤1 节；单日上限待定（建议 ≤2 节）；不与视频批次并行 |
| 并发 | **单实例、单窗口、单标签**；不与视频批次并行 |
