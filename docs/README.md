## 3. 阅读/使用须知（硬约束）

1. **只做视频任务点 28/59**：测验只填不交（本次不做）、直播 8.1/8.2 与阅读 9.1 不做。**2026-11-07 更新**：阶段D 规划解禁；P1/P2/P3 已放行 MVP（只读侦查+受控回填/新代码，**不提交**）；测试仍只填不交；生产提交 G6 未授权。（旧句保留为历史）
2. **2x 上限 + 静音 + 可后台/最小化是用户明确选择，账号风险用户自担**（Q12）。
3. **逐节确认制**：每节跑完给证据，用户确认后才跑下一节；每节需 1 次确认（Q21）。
4. **一页一页单独测试**，不一次性全量（Q12）。
5. 本次**不下载模型、不下载浏览器内核、不改系统 Python**（Q11）。
6. 不接管/不截图/不切前台用户已有 Chrome 窗口；只用独立 Chrome 实例。
7. 未验证事项一律标"未验证"；未定事项一律写"待定"，不脑补。
