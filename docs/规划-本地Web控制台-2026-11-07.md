## 1. 目标与范围

### 1.1 一句话目标

在**本机**做一个**本地 Web 控制台（FastAPI+uvicorn）**：用户用浏览器打开 `127.0.0.1` 即可查看任务进度、**导出题目 Word/文本**、**导入外部 AI 答案**（粘贴文本 / DOCX / JSON）、做覆盖校验、**代填并提交**；提交前默认显示确认按钮，用户勾选「免确认自动提交」才直提；全程留证据与审计日志。

### 1.2 用户确认（2026-11-07 前端 4 项 + 追加 3 项）

| # | 用户确认 | 本方案落地 |
|---|---|---|
| 1 | 导出格式 **Word（DOCX）** 为主；不做 PDF/MD 为主（Word 可另存） | §5 导出 DOCX 模板 + 纯文本辅助；不实现 PDF/MD 导出 |
| 2 | **代填 + 代提交**：导入答案后自动回填并提交；**提交前界面显示确认按钮，默认需点击确认**；若用户勾选「免确认自动提交」则直提 | §7 默认确认模式 + 免确认复选框（默认关、二次提示、审计记录） |

| 7 | **面向无计算机基础用户**：界面不展示代码/技术内容，只展示「完成截图 + 答题成绩 + 题目」；任务卡用章节中文名；状态只四词；异常只中文提示+重试；技术配置放「设置→高级」默认折叠；全站浅色 | §4.2 UI 文案规范 + §7.5 用户可见文案；五屏按此改写 |

### 1.4 术语

- **控制台**：本方案的单页本地 Web UI（浏览器打开 `127.0.0.1:port`）。
- **题目导出**：把某节题目（题干/选项/题型）导出为 DOCX 或文本，供外部 AI 作答。
- **外部 AI 答案**：用户把导出题目交给其他 AI 后拿回的答案（文本/DOCX/JSON）。
- **覆盖校验**：确认答案对页面题号 1..N 全覆盖、选项合法、无重复/冲突。
- **确认提交**：默认模式，页面显示「确认提交」按钮，用户点击后才提交。
- **免确认自动提交**：可选模式，用户勾选后导入/填答完成即提交（默认关，需二次提示）。

## 3. 技术选型（FastAPI+uvicorn 主方案；零安装为备选）

### 3.1 约束

用户 2026-11-07 **已授权安装依赖并自行选更优方案**（更新原「零安装」约束）。本轮技术选型：后端 **FastAPI + uvicorn**、Word **python-docx**、PDF 抽取 **pypdf**；前端保持**原生 HTML/JS（无 npm、无构建、无 CDN）**。原「零安装（stdlib http.server + 自研 DOCX）」**降为备选**（无网/受限环境）。

| 前端 | **原生 HTML + CSS + Vanilla JS**（单页，**浅色主题**） | 无构建、无 npm、无 CDN；离线可用 |

### 3.3 python-docx：从「实测缺失」到「已授权安装」

- **原实测（2026-11-07，历史证据）**：`work/.venv`、`D:/pyai/pych/.venv`、`D:/python/.venv`、系统 Python 均 `ModuleNotFoundError: No module named 'docx'`。
- **用户 2026-11-07 拍板：允许安装依赖、自行选更优方案** → DOCX 主实现定为 **python-docx**。
- **安装（已授权，待执行/待实测）**：`work/.venv\Scripts\python.exe -m pip install python-docx`（pip 已配清华源）；安装时点由用户在场确认，安装后记录版本。
- **依赖清单**：`fastapi`、`uvicorn`、`python-docx`、`pypdf`（均已授权）；前端无 npm 依赖。
- **零安装自研 DOCX 降为备选**（仅在无网/受限环境使用）；复杂 Word 兼容以 python-docx 为准。

### 3.4 启动与网络

- 启动：`uvicorn app:app --host 127.0.0.1 --port 8765`（或 `python -m uvicorn ...`；端口可配）；启动后打印带 token 的本地 URL。
- **仅绑定 127.0.0.1**；不监听 0.0.0.0；**不做手机端**（用户已确认）。
- 无外部 CDN/字体/图片；前端资源全部本地文件；离线可打开。
- 不抢前台：控制台由用户自行用浏览器打开；自动化操作在独立 Chrome/CDP 中后台进行（沿用禁止抢前台铁律）。

### 3.5 接口（全部本地 JSON，单进程串行）

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/status` | 课程进度/任务点/授权/提交模式/运行状态 |
| GET | `/api/tasks` | 28 测验 + 21 视频任务清单与状态（只读） |
| POST | `/api/export` | 导出题目（`format=docx` 或 `text`，`sec`） |
| POST | `/api/import` | 导入答案（文本/DOCX/JSON/**PDF**），返回解析表+失败题 |
| POST | `/api/fill` | 代填（不提交）；返回填答证据路径 |
| POST | `/api/submit` | 提交（`mode=confirm` 或 `auto`，需 token） |
| GET | `/api/evidence/<sec>` | 查看该节证据/日志 |
| POST | `/api/stop` | 停止当前动作（STOP 文件） |

- FastAPI 路由 + 单进程、串行队列：同一时刻只允许一个「导出/填答/提交」动作；提交不可重入。
- 状态机：`idle → exporting/importing/filling → awaiting_confirm → submitting → done/failed/unknown`。

## 4. 五屏设计

### 4.0 界面主题（浅色，2026-11-07 拍板）

- **唯一主题：浅色**（替换原深色假设）；不做深色切换/自动跟随系统。
- 色板建议：背景 `#F7F8FA`、卡片 `#FFFFFF`、主色 `#2563EB`、主文字 `#111827`、次文字 `#4B5563`、边框 `#E5E7EB`、成功 `#16A34A`、警告 `#D97706`、危险 `#DC2626`。
- 可读性：正文对比度 ≥4.5:1；系统字体；不引外部字体/CDN；按钮/表单统一浅色风格。
- 无障碍：错误/成功状态不只靠颜色，附文字/图标。

| # | 屏幕 | 目标 | 关键控件/展示（面向非技术用户） | 出口 |
|---|---|---|---|---|
| 1 | **总览** | 一屏看清现状 | 课程进度（如 11/59）、各章节状态（已完成/进行中/待开始/有问题）、最近成绩、**查看完成截图**、一个「停止」按钮 | 进入任务屏 |
| 2 | **任务** | 选择要处理的小节 | 任务卡=**章节中文名** + 状态四词 + 「查看题目 / 查看截图 / 开始答题」 | 选择某节 → 题目屏 |
| 3 | **题目导出** | 导出题目给外部 AI | 选章节中文名 → 预览题目 → 「导出 Word 题目」/「复制题目文字」（题目不含答案） | 文件交给外部 AI |
| 4 | **导入与校验** | 粘贴/上传外部 AI 答案 | 粘贴答案框、上传答案文件（Word/PDF/文本）、看到「共 N 题，可作答 N 题」「第 2 题没看懂」+ 修改 + 「重新检查」 | 校验通过 → 代填 |
| 5 | **代填与提交** | 预览、确认/免确认提交 | 只展示题目 + 答案 + 预计成绩 + 「查看截图」；**默认「确认提交」按钮**；可勾选「不再询问，直接提交」；提交后显示成绩与完成截图 | 提交结果 / 下一节 |

### 4.1 五屏补充约束

- 屏 3 导出**不带正确答案**（避免外部 AI 被答案污染）；人工核对用的「带答案版」单独入口/后续再做【待拍板】。
- 屏 4 **覆盖不足 100% 时禁止进入代填**（可人工补题/修改后重校验）；缺答案的题用中文逐条列出（如「第 2 题没有答案」）。
- 屏 5 默认**确认提交**；「不再询问，直接提交」默认关，勾选时中文二次提示并记录。
- **全站浅色主题**（§4.0）；不做深色切换。
- 导出/导入均优先支持 Word/PDF 文件，文本粘贴保留为兜底（文件名/路径只在保存与排错时使用，不在主界面展示）。

### 4.2 面向非技术用户的信息呈现（UI 文案规范）

**目标用户**：无计算机基础；不读代码、不懂技术名词。界面**只展示三类内容**：①**完成截图** ②**答题成绩** ③**题目**（另加进度与操作按钮）。日志、JSON、路径、文件名、接口、技术参数一律不上主界面。

| 规则 | 要求 |
|---|---|
| 任务卡命名 | 用**章节中文名**（如「第一章 第一节 形势与政策」）；无中文名时用「第一章 第一节」+「视频/测验」标签；**不显示** sec/chapterId/URL |
| 状态用词 | 只允许四个：**已完成 / 进行中 / 待开始 / 有问题**；不显示 pending/running/unknown、HTTP 码、错误码 |
| 主界面内容 | 只放：题目、答案、成绩、完成截图、进度、操作按钮；**不出现** JSON/jsonl、路径、文件名、CDP、enc、ratio、DOM、iframe、frame、token、API、端口、日志、哈希、模型名/量化、conf/attempts/jobUnfinishCount、NaN |
| 异常提示 | 一句话中文 + 「重试」按钮（如「这次没成功，请点重试」「还有 2 题没有答案，请补上」）；不显示英文、错误码、堆栈 |
| 技术配置 | 全部收进 **「设置 → 高级」**，默认折叠；普通用户无需进入（端口、访问口令、日志位置、依赖状态、模型参数等） |
| 按钮文案 | 中文动词：开始答题 / 查看题目 / 导出题目 / 查看完成截图 / 查看成绩 / 确认提交 / 重试 / 下一步；不用 submit/export/retry 等英文 |
| 视觉与操作 | 全站浅色（§4.0）；大字号、大按钮、一屏一个主要动作；不展示多级技术弹窗 |

> 后台与审计仍保留技术字段（路径/JSON/日志），但**只用于排错**，不在主界面呈现；需要时由「设置→高级」或开发者查看。

## 5. 导出格式规范（DOCX / 文本）

### 5.1 DOCX 题目模板（主格式）

| 部分 | 内容 |
|---|---|
| 标题 | `《形势与政策》第 <sec> 节 章节测验题目` |
| 说明 | 「请按题号作答；答案写在每题『答案：』后；多选写多个字母（如 B,C,D）」 |
| 题目表 | 列：**题号 / 题型 / 题干 / 选项（A. … / B. …） / 答案：**（答案栏留空给外部 AI 填） |
| 页脚 | 导出时间 + 节号 + 题数；⚠ 不含正确答案 |

- 生成方式：**python-docx**（已授权安装；模板见上表）。
- 文件名：`quiz-<sec>-题目-<YYYYMMDD-HHmm>.docx`；编码 UTF-8。
- 题干/选项文本使用**视觉识别转写结果**（阶段D §3.0：DOM 被 font-cxsecret 混淆，不导出 DOM 原文）。

### 5.2 纯文本模板（复制用）

~~~
第 <sec> 节 章节测验（共 N 题）
1. 题干……
   A. ……  B. ……
   答案：
2. ……
~~~

- 导出时把文本同步显示在页面，便于一键复制给外部 AI。

## 6. 导入格式规范（文本 / DOCX / JSON / PDF）

### 6.1 粘贴文本

支持格式（每题一行或块）：

~~~
1. A
2. D
3. C
4. B,C,D
5. A,C,D
~~~

- 行首题号：`1`、`1.`、`1、`、`1）` 均可；
- 多选用 `,` / `，` / `、` 分隔；判断题支持 `正确/错误`、`对/错`、`T/F`、`√/×`；
- 忽略空行、题干行、注释行；无法识别的行进入失败列表。

### 6.2 DOCX

- 支持两种形态：①**表格**（两列：题号→答案，或 序号→答案）；②**段落**（同 §6.1 行式文本）。
- 解析优先级：表格 → 段落；只取答案列/答案段，忽略题干；合并单元格等复杂结构以 python-docx 解析为准（备选自研不保证）。
- 解析失败时返回失败题列表与原片段，供人工改。

### 6.3 JSON

- 兼容 `chaoxing-answer/1.1` 与简化形式：

~~~
{"answers":[{"index":1,"type":"single","value":["A"]},
            {"index":4,"type":"multiple","value":["B","C","D"]}]}
~~~

- 也接受 `{"1":"A","2":"D"}` 映射形式；`source` 标注 `external_ai`。
- 未知题型/越界值 → 该题进失败列表。

### 6.4 PDF（pypdf 抽取）

- 支持**文本型 PDF**（外部 AI 导出的答案表/答案文本）；用 `pypdf` 逐页 `extract_text()`，按 §6.1 行式规则解析。
- **不支持**扫描件/图片型 PDF（无 OCR；如需 OCR 需另行授权安装，见 R10 / §10 Q7）。
- 多页合并解析；忽略页眉/页脚噪声；无法解析的页/题进失败列表。
- 建议上限 ≤20 页 / ≤10 MB（可配）；超限拒绝并提示。

### 6.5 解析与覆盖校验规则

| 检查 | 规则 | 不通过 |
|---|---|---|
| 题号范围 | 必须在 1..N 且 N=页面题数 | 失败题列表 |
| 重复 | 同一题号多答案/冲突 | 失败题列表 |
| 缺失 | 任一题无答案 | **覆盖不足，禁止代填** |
| 选项合法 | 答案 key 必须在该题选项内 | 失败题列表 |
| 多选空/单答案 | 多选至少 1 项；单项选择题数=1 | 失败题列表/提示 |
| 判断题归一 | 正确/错误/对/错/T/F/√/× → true/false | 归一后校验 |
| 答案冲突 | 文本 vs DOCX/JSON/PDF 多次导入不一致 | 高亮，需人工选定 |

- **覆盖 100% + 全部合法** 才允许进入「代填」；失败题逐条展示（题号/原因/原文片段）。
- 人工在屏 4 修改后必须**重新校验**，通过才可继续。

## 7. 代填与提交闸门

> 本节为内部实现与安全约定；**用户可见的文案见 §7.5**（短句中文、无技术术语）。

### 7.1 两种提交模式

| 模式 | 默认 | 行为 | 适用 |
|---|---|---|---|
| **确认提交** | ✅ 默认 | 填答完成 → 显示预提交预览 → 用户点「**确认提交**」→ 提交 | 普通使用；每节一次确认 |
| **免确认自动提交** | ❌ 默认关 | 填答完成 → 直接提交（不显示确认按钮） | 用户主动勾选「免确认自动提交」；勾选时二次提示并写审计 |

### 7.2 提交流程（单节）

1. **覆盖校验**：100% 且合法（§6.5）；显示来源（本地模型/外部 AI）与题数。
2. **代填**：按显示字母点击选项元素（阶段D §5.8：默认 DOM click，真实鼠标备选）；回填后截图/aria-checked 核对。
3. **预提交预览**（确认模式）：题干/答案/置信度/来源/证据路径/**剩余次数（未知则标注）**/不可逆警告。
4. **提交**：调用阶段D §4.7 链路（顶层 `#workpop/#popok` → `confirmSubmitWork()` → `addStudentWorkNewWeb`）。
5. **结果记录**：分数/进度/任务点/第 N 次作答/截图；写 `submit.json` 与 audit。
6. **失败/未知**：**不重试提交**；留证、标 unknown、提示用户。

### 7.3 审计与证据（每次提交必留）

| 文件 | 内容 |
|---|---|
| `answers.jsonl` | 逐题答案/来源/覆盖标记 |
| `submit.json` | 时间/节号/模式（confirm/auto）/答案摘要/结果分数/进度变化/次数 |
| `audit.jsonl` | who（本地用户）/when/mode/IP（127.0.0.1）/是否免确认/是否人工修改 |
| 截图 | 填答后、确认页、结果页 |

### 7.4 授权与安全边界

- 用户 2026-11-07 已确认前端支持**代填+代提交**；**默认仍需点击确认**。
- **免确认 = 用户主动放弃单次确认**：默认关、勾选需二次弹窗、每次记录；建议仅单节/单次生效（是否长期开启见 §10）。
- **提交不可逆**：1.1–2.3 均已用掉第 1 次作答；提交失败/未知不重试。
- 生产批量放量是否仍需 G6/逐节确认：本方案默认沿用阶段D 边界，待用户拍板（§10）。

### 7.5 用户可见文案（去术语）

| 场景 | 界面只显示 | 禁止出现 |
|---|---|---|
| 提交前确认 | 「提交后不能修改，确认提交？」+「确认提交 / 取消」 | submit/post/接口/次数码 |
| 免确认选项 | 「以后不再询问，直接提交（不推荐）」 | auto/threshold |
| 缺答案 | 「还有 2 题没有答案，请补上」 | coverage/JSON |
| 解析失败 | 「有 2 题没看懂，请检查后重试」 | parse error/exception |
| 提交成功 | 「提交成功！成绩 60 分，第 2.3 节已完成」 | HTTP/200/接口 |
| 提交失败/未知 | 「这次没成功，请点重试」+「重试」按钮 | 错误码/堆栈/英文 |
| 状态 | 已完成 / 进行中 / 待开始 / 有问题 | pending/running/unknown |
| 看证据 | 「查看完成截图」「查看成绩」 | 路径/jsonl/哈希 |

> 所有提示语用短句中文；用户点「重试」即重试当前步骤；技术细节写后台日志，不弹给用户。

## 8. 安全与合规

1. **仅本机**：绑定 `127.0.0.1`，随机 token 校验；不做手机/公网；不监听 0.0.0.0。
2. **依赖边界**：仅安装已授权依赖（`fastapi`/`uvicorn`/`python-docx`/`pypdf`）；前端无 npm/无 CDN；不引入其他包。安装结果与版本【待实测】。
3. **不抢前台**：UI 由用户打开；自动化走独立 Chrome CDP，禁止 OS 抢焦点/置前。
4. **提交安全**：默认确认、免确认 opt-in+二次提示、提交不可逆、失败不重试。
5. **外部 AI 答案**：属外部来源，必须覆盖校验+人工核对；系统不自动把题目外发（用户自行复制到外部 AI 属用户行为）。
6. **数据**：题目/答案/截图/账号态本地留存、不进 git、不外发；不含 cookie/token。
7. **不伪造**：不改接口报文、不伪造进度、不绕验证码/风控。
8. **面向非技术用户**：主界面不展示代码/技术术语/日志；异常只显示中文提示 + 「重试」；技术配置仅在「设置→高级」默认折叠（详见 §4.2/§7.5）。
9. **技术细节后置**：JSON/路径/日志/端口/模型参数只出现在后台与高级设置，不作为普通用户操作前置条件。
