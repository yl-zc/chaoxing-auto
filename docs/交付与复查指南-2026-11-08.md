## 0. 一句话

把压缩包解压到一个短路径，**只需双击 4 个中文按钮**（首次安装 → 启动控制台 → 自检 → 生成报告），在浏览器里按提示扫码、点「开始答题」、看「成绩 + 完成截图」；出问题点「重试」，仍不行就在「设置 → 高级」里导出排错信息发给对接人。

## 1. 目录结构与进包 / 不进包

### 1.1 推荐交付包结构（目标形态）

~~~
学习通自动化测试包-2026-11-08/
├─ 首次安装.bat            # 仅第一次运行（需联网）
├─ 启动控制台.bat          # 双击后打开浏览器控制台
├─ 自检.bat                # 检查环境/依赖/端口
├─ 生成报告.bat            # 汇总成绩与进度
├─ 导出题目.bat            # 导出某节题目 Word
├─ app/                    # 控制台与自动化程序
├─ tools/                  # 自检/报告/导出脚本
├─ configs/                # 配置示例（不含账号密码）
├─ requirements.lock       # 锁定依赖版本
├─ manifest.json           # 包版本/文件清单/哈希
├─ docs/                   # 使用说明 + 本指南
├─ reports/                # 生成报告输出（空目录）
└─ runs/                   # 每节运行日志与证据（运行后产生）
~~~

### 1.2 进包 / 不进包

| 进包 | 不进包（重要） |
|---|---|
| 程序代码、工具脚本、中文启动按钮、配置示例、文档、依赖版本锁 | ❌ `.venv` / 虚拟环境（体积大、换机不可用） |
| `manifest.json`（版本+文件清单+SHA-256） | ❌ `chrome-profile` / `edge-profile`（登录态=账号凭据） |
| 空目录 `runs/`、`reports/` 及示例格式 | ❌ 运行日志原件（含页面内容/PII，需脱敏后另附） |
| 必要的第三方许可/声明 | ❌ 截图原始文件（含姓名/班级，按需单独给，不随包扩散） |
| — | ❌ 模型权重（体积大、本机已有；不进包） |
| — | ❌ `.git`、`__pycache__`、`*.pid`、`STOP`、临时文件、旧归档 |

> 交付包**不得包含**：账号密码、Cookie/Token、二维码截图、用户真实姓名与学号。打包前用 `manifest.json` 对文件清单与哈希做一次核对。

## 2. 日志规范

| 项 | 规范 |
|---|---|
| 编码 | **UTF-8（无 BOM）**；日志内中文不转义 |
| 目录 | 每节独立：`runs/<开始时间YYYYMMDD-HHMMSS>/<节号>/`（如 `runs/20261108-101500/2.4/`） |
| 分开记录 | **控制台/服务日志**（`logs/server.log`、`logs/console.log`）与**每节运行日志**（`run.log`）分开；daemon 与前台输出不混写 |
| 每节内容 | `run.log`（动作流水）、`play_samples.jsonl`（视频采样）、`answers.jsonl`（逐题答案/来源）、`submit.json`（提交结果/成绩）、`screenshots/`（关键截图） |
| 脱敏 | 不写密码/Cookie/Token/二维码；姓名、学号、班级等 PII 用 `***` 或省略；URL 中 `enc` 等业务参数可保留但不得含个人凭据 |
| 轮转 | 每次运行新建时间目录；单文件 ≤10 MB，自动切分；仅保留最近 **10 次**运行目录（可在「设置→高级」调整） |
| 排错导出 | 「设置→高级」提供「导出排错信息」：打包脱敏后的日志+版本+错误摘要；**不包含**登录态与截图原图（截图需用户自行决定是否提供） |

## 3. 一键命令（目标形态；脚本名以包内为准）

| 场景 | 用户操作 | 底层命令（供复查者） | 说明 |
|---|---|---|---|
| 首次准备 | 双击 `首次安装.bat` | `python -m venv .venv` → `.venv\Scripts\python.exe -m pip install -r requirements.lock` | 仅第一次；需联网；已配国内 pip 源【待实测】 |
| 启动控制台 | 双击 `启动控制台.bat` | `.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8770` | 启动后浏览器打开 `http://127.0.0.1:8770`；**当前实际端口 8770，最终以启动脚本输出为准**【待实测】 |
| 自检 | 双击 `自检.bat` | `python tools/doctor.py --json` | 检查 Python/依赖/端口/Chrome；结果中文显示 |
| 生成报告 | 双击 `生成报告.bat` | `python tools/report.py --out reports` | 汇总进度/成绩/证据清单 |
| 导出题目 | 双击 `导出题目.bat` | `python tools/export_quiz.py --sec <节号> --format docx` | 输出 Word 题目（不含答案） |
| 停止 | 控制台点「停止」 | 写 `runs/<本次>/STOP` | 优雅停；不要直接关命令行黑窗 |

> 不要双击 `.py` 文件；只双击 `.bat` 中文按钮。**本包一键脚本均为 `.cmd`/`.bat`（不是 `.py`）**。命令路径/参数/端口以实际交付包与启动脚本输出为准。

## 4. 复查清单

### 4.1 进度与任务点核对（对照用）

| 核对项 | 应看到 | 说明 |
|---|---|---|
| 课程总进度 | **12/59**（本指南编写时基线） | 用户后续可能继续做，以实际页面数字为准 |
| 已完成测验节 | 1.1、2.2、1.2、2.3、**1.3** | 每节任务点应 **2→0**（视频+测验） |
| 每节任务点 | 进入前 2 / 完成后 0 | 若只完成视频则 2→1；若 1 未变即失败 |
| 剩余任务 | 视频 21 节（2.4–7.3）+ 测验 **23 节** | 不含直播 8.1/8.2、阅读 9.1 |

### 4.2 每节成绩（已有交付数据）

| 节 | 成绩 | 说明 |
|---|---|---|
| 1.1 | **100/100** | 第 1 次作答，5/5 全对 |
| 1.2 | **100/100** | A→C 策略实验，5 题全对 |
| **1.3** | **100/100** | 已完成，任务点 1→0（新增，2026-11-08 口径） |
| 2.2 | **80/100** | Q4/Q5 人工核验覆盖 +40；Q1/Q3 多选失分 |
| 2.3 | **60/100** | Q1/Q2 失分（多选过度勾选/概念细节） |

> 成绩来源：`runs/.../submit.json` 与页面结果页截图；平台不公布标准答案，复查以「分数+任务点」为准。

### 4.3 证据目录（每节齐全才算通过）

| 文件 | 用途 |
|---|---|
| `run.log` | 打开/填答/提交动作流水（时间顺序） |
| `answers.jsonl` | 逐题答案、来源（本地模型/外部 AI）、是否提交 |
| `submit.json` | 提交时间、模式（确认/免确认）、成绩、进度变化、第几次作答 |
| `screenshots/` | 填答后、确认页、结果页截图 |
| `play_samples.jsonl` | 视频节：播放采样（连续性/时长） |

### 4.4 错误码与处置

| 码 | 含义 | 用户处置 |
|---|---|---|
| 0 | 完成且判分通过 | 无需处理 |
| 1 | 未完成/待判分 | 等 1–2 分钟后点「重试」 |
| 2 | 主动停止或存在失败 | 看「设置→高级」错误摘要；重试 1 次 |
| 3 | 程序异常 | 点「重试」；仍失败→导出排错信息发对接人 |
| 4 | 判分未完成（不可信） | 不要当成功；重试或人工核对 |
| 打不开控制台 | 端口占用/未启动 | 重新双击「启动控制台.bat」；仍不行看 `logs/server.log` |
| 提交结果未知 | 网络/页面异常 | **不要重复点提交**；截图反馈对接人 |

## 5. 独立测试步骤（用户视角，不假设技术背景）

1. **解压**：把压缩包解压到短路径（如 `D:\学习通测试`）；不要直接在压缩包里双击。
2. **首次安装**（只第一次）：双击 `首次安装.bat`，看到「安装完成」字样再继续；需要联网。
3. **启动**：双击 `启动控制台.bat`；浏览器会自动打开；若没有，手动打开 `http://127.0.0.1:8770`（端口以启动脚本输出的地址为准；当前实际 8770）。
4. **登录**：按页面提示，用**你自己的手机学习通扫码**；不要把二维码/密码发给任何人。
5. **开始答题**：点「任务」→选章节（中文名）→点「开始答题」；系统自动填答案。
6. **确认提交**：页面只显示题目+答案+预计成绩；默认需点「确认提交」；**提交后不能修改**。不想每次确认可勾「不再询问，直接提交（不推荐）」。
7. **看结果**：提交后显示「成绩 + 完成截图 + 进度」；状态只会是「已完成/进行中/待开始/有问题」。
8. **出问题**：点「重试」；仍不行，点「设置 → 高级」→「导出排错信息」，把压缩包发给对接人（不要附密码/二维码）。
9. **结束**：先点「停止」，再关闭浏览器；不要直接关黑色命令行窗口。
10. **不要做**：不改文件、不删目录、不把截图/日志发到公开群；单端登录（跑课期间手机/电脑不要同时登同账号）。
